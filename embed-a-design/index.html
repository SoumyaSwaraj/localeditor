Embed a design

Show a design on your page, read-only.

Copy an embed code from the share options and paste it into a blog post or a docs page. Visitors see your design page by page and can press a button to open a copy in the studio. The viewer never edits, saves or uploads anything.

What it does

  • Shows every page of a design, with page buttons and keyboard control
  • A button that opens the design in the studio, so a visitor edits their own copy
  • Follows the visitor's light or dark choice, or add theme=light or theme=dark to force one
  • Reads a template link, or a design file kept on the same site
  • Drawn on the visitor's device with the studio's own renderer

How it works

  1. Open your design in the studio and choose Share as template link from the File menu.
  2. Choose Copy embed code.
  3. Paste the code into your page. Photos are not part of a link, so they show as empty slots.

Your files stay on this device

The viewer only reads. It saves nothing, adds nothing to Your designs and asks no other site for anything. A template link keeps the design after the #, which browsers do not send to a server, and pictures named by an https address in a design are never fetched.

Questions

Short, honest answers.

More on the privacy and install page.

Can a visitor change my design?

No. The viewer is read-only. The open button gives them their own copy to edit, and your original stays as it is.

Do photos show?

Not from a template link, which leaves photos out: they show as empty slots. A design file kept on the same site shows its pictures when they sit next to it as relative paths.

Can a design run code in the viewer?

No. A design is data. It goes through the same reader and safety checks as the studio and is drawn on a canvas. Text from it is never added to the page as HTML.

Why does the open button show an address?

A frame without pop-up permission cannot open a new tab, so the viewer shows the address to copy instead. The copied embed code includes the permission.
