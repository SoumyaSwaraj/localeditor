Open design file format

Designs as plain files people and agents can edit.

A design is one plain file: pages, layers, text and styles as data. A person or an agent can write one, open it in the studio and keep editing, and the studio saves the same format back.

What it does

  • Readable JSON with a published schema
  • Save with the photos inside, or as a template with empty photo slots
  • Checked on opening: anything that is not plain design data is refused, and problems are listed with where they are
  • Shorthand for agents, such as "x": "center" and "w": "90%"
  • Every layer has a short readable id, so a request can say “change the title”

How it works

  1. In the studio, choose File, then Save as design file. Or write a .ledesign.json file yourself.
  2. Open it from File, Open design file, or from the Your designs panel.
  3. Edit it in the studio and save it back.

Your files stay on this device

Design files are opened on this device and checked against a fixed list of fields. Nothing is uploaded.

Questions

Short, honest answers.

More on the privacy and install page.

Can a design file contain scripts?

No. Scripts, HTML and anything else that is not plain design data are refused when you open the file.

Where is the format described?

The JSON Schema is published at localeditor.net/schema/design-1.json.

Are my photos kept in the file?

Your choice. Save with photos for one self-contained file, or as a template, where photos become empty photo slots.
