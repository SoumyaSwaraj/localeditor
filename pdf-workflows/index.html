Saved PDF workflows

Do the same PDF jobs in one go, every time.

Build a list of steps once and run it on one file or a whole batch. Start from a built-in workflow or make your own, save it on this device, and share it as a small file that holds the steps and never a password.

What it does

  • Steps include merge, make a pack, rotate, keep or delete pages, number pages, headers and footers, Bates numbers, watermark, stamp, remove hidden details, make safe to send, compress and password-protect
  • Built-in workflows such as safe to send, email-friendly, numbered draft and client pack
  • Run on one file or many, and download the results together as a zip
  • Save your own, and share as a .lepdfworkflow file

How it works

  1. Choose a built-in workflow or start your own and add steps.
  2. Add the PDFs to run it on.
  3. Run it and download the results.

Your files stay on this device

The files are read and written by your browser on this device. Nothing is uploaded. A workflow file holds only the steps and settings. A password is asked for each time you run a workflow that locks files, and is never saved in it.

Questions

Short, honest answers.

More on the privacy and install page.

Can a workflow file run code?

No. It is data: a named list of steps from a fixed set. A file with anything else is refused when you open it.

Where are my workflows kept?

In this browser, on this device. Export one to keep a copy or to send it to someone.

What do I get back?

One file when there is one result, or one zip when there are several. Files run one by one unless a step, such as merge, combines them.
