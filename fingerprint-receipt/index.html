Fingerprint receipt

Prove a copy is the same file.

A fingerprint is a 64-character code worked out from every byte of a file. Make one for any file, print or send a one-page receipt with a QR code, and anyone can use the check page to see whether their copy matches.

What it does

  • A SHA-256 fingerprint of any file, with its size and page count
  • A one-page receipt PDF with a QR code, and a picture card
  • A check link that carries the fingerprint after the #, which browsers never send to a server
  • Optionally, a copy with the receipt as its last page, or the fingerprint in its details

How it works

  1. Choose the file, or use the one you have open.
  2. Copy the fingerprint or download the receipt.
  3. Anyone can open the check page, drop in their copy and compare.

Your files stay on this device

The fingerprint is worked out by your browser on this device and the file is not uploaded. The check page does the same: the file never leaves the device that checks it.

Questions

Short, honest answers.

More on the privacy and install page.

What does a matching fingerprint show?

That a copy is byte for byte the same file as when the receipt was made.

What does it not show?

It does not show who made the file or when it was first created. Any change, even re-saving the file, gives a different fingerprint.

Is it a digital signature?

No. A fingerprint proves a copy is unchanged. It does not prove who made it.
