# Handover: picking this up in a fresh local clone

Written 17 November 2026. State of `main` at commit `c961fbd` (the branch `evergrow/focused-pasteur-t84h3j` is the same commit plus this file).

## What this is

LocalEditor (https://localeditor.net/): a private, offline-first, installable web app. A design and photo studio with an Expert mode, a PDF studio, 36 quick makers, a chart maker, a styled QR code maker and 33 small tools. Everything runs on the visitor's device. Static files only, hosted on S3 behind CloudFront. Vanilla ES2018 scripts on `window`, no bundler, no framework, no `package.json`.

## Set up a local machine

Node 22 was used. The tests need Playwright and its Chromium, which are not in the repo:

```bash
npm install --no-save playwright
npx playwright install chromium
```

Run the site:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765/studio/`.

Not in the repo (git-ignored), fetched by scripts when wanted:

- Large background-remover models: `node scripts/fetch-models.js pro` (over 100 MB each). Without them those options say "Not available on this copy".
- Chinese, Japanese and Korean fonts: `node scripts/fetch-fonts.js --cjk` (the deploy script fetches them if missing).
- Extra text-recognition languages: `node scripts/fetch-ocr-data.js`. Sample camera RAW files: `node scripts/fetch-raw-samples.js`.

## Everyday commands

```bash
node scripts/build-pages.js      # after editing assets/data/site.json: hubs, feature pages, search list
node scripts/build.js            # always after adding, removing or renaming files: sw.js, manifests, packs.json, sitemap, llms.txt
node tests/run.js smoke.test.js  # one test file by exact name
TEST_CASE="text in the case name" node tests/run.js collage.test.js
tests/run-all.sh 2               # whole suite, each file in its own process, two at a time
```

- Do not run more than two or three browsers at once: pages crash and tests time out, which looks like product bugs.
- A failure that passes alone is not automatically a flake. Twice in this project it was a real race (collage settings after undo; a live-link message overwritten). Re-run alone several times and read the assertion before deciding.
- Last full run: 1,253 passed, 1 known, 2 failed. The two were waits in offline-worker tests that have since been lengthened; the full suite was not re-run after that.

## Rules that are easy to break

- **Budgets.** `tests/loading.test.js` caps what blocks first paint (studio about 243 KB gzip against a 250 KB target, little headroom). New features load through the loader maps `assets/js/le-studio-lazy.js` and `assets/js/le-pdf-studio-lazy.js`; never add a blocking `<script>`.
- **Format first.** All state is plain data in the document, sanitised in `assets/js/le-objects.js` and `assets/js/le-project.js`, and round-tripped by the open format (`assets/js/le-design.js`, `schema/design-1.json`). Documents, recipes and workflows never carry script.
- **Generated files.** `sw.js`, `sitemap.xml`, `llms.txt`, `manifest*.webmanifest`, `assets/data/packs.json`, `assets/data/search.json`, hub and feature pages are generated. Edit the source (`scripts/build.js`, `scripts/build-pages.js`, `assets/data/site.json`) and regenerate. They are committed on `main`; `CLAUDE.md`'s "do not commit `sw.js` from a feature branch" is about short-lived feature branches.
- **Tokens only** in interface CSS; `tests/brand.test.js` rejects hard-coded retired colours. Five themes are token sets in `assets/css/app.css` (generated by `tools/themes/build.py`).
- **Licences**: MIT, ISC, BSD, Apache or OFL only. The one approved exception is the camera RAW decoder (LGPL, downloaded on demand, licence shown on `/licenses/`).
- **No third-party requests** unless the person starts them (stock photo search). No CDN.
- Stock API keys live only in `localStorage` key `le-stock-keys`; never log or commit them.
