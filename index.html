Questions

Short, honest answers.

More detail on the privacy and install page.

Do my photos or PDFs leave this device?

No. The studios and tools run inside your browser. There is no account and no upload; files are read, edited and saved on your device. The only time the app reaches the internet for you is when you ask it to, for example to search stock photos.

Does it work offline?

Yes. After the first visit the app keeps working without a connection. Install it to your home screen or dock and it opens like any other app. Large extras, such as more fonts, are saved for offline use when you first use them.

Is it really free?

Yes. There is no sign-up, no watermark on exports and no paid tier.

What is a recipe, and what is a project file?

A recipe is a small .leworkflow file listing edits, such as warmth and contrast, that you can apply to any photo and share. A project is a .leproject file holding a whole design, with its pages, layers and photos, so you can reopen it later. Neither can contain code.

Can it remove a background automatically?

Not yet. Today you can remove a flat colour or paint a background away by hand. Automatic removal is being tested and will only arrive if it can run on your device.

Which browsers and devices does it support?

Current versions of Chrome, Edge, Safari and Firefox, on phones, tablets and computers. Very large photos and long PDFs work best on a computer.
