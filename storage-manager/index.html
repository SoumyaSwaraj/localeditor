Storage manager

See what is stored here, and clear it in one tap.

Every cache has an owner, a size and a clear button. The storage manager lists saved work, the offline app, downloaded fonts, graphics and models, RAW working copies, and anything else the app keeps on this device, and holds the setting for how features download.

What it does

  • Lists saved designs, the offline app, fonts, graphics, models and RAW working copies
  • Shows how much space each part takes
  • Clear one category or everything
  • Choose whether features download automatically as you use them or ask first, or download the basic editor, models, Expert editor or everything now for offline use
  • Ask the browser to keep your saved work when space runs low

How it works

  1. Open the storage manager from the menu on any page.
  2. Check what is stored and how large it is.
  3. Clear what you do not need.

Your files stay on this device

The storage manager only looks at what this app stored in this browser. It does not read other sites' data or your files.

Questions

Short, honest answers.

More on the privacy and install page.

Will clearing storage delete my designs?

Clearing saved work does. Clearing fonts or graphics only removes downloads, which come back when you use them again.

Why would the browser delete my work?

Browsers can clear site data when the device is low on space. Asking for persistent storage makes that less likely, and saving a project file keeps a copy you control.
