How to add page numbers to a PDF

  1. Drop your PDF into the box or tap to choose it.
  2. Pick the position, number format, start number, font size and margin, and check the live preview.
  3. Click Add page numbers and download the numbered PDF.

What is adding page numbers to a PDF?

Adding page numbers to a PDF means drawing a number on every page so printed and shared documents are easy to navigate and reference. This tool writes real vector text (Helvetica) into each page with the open-source pdf-lib library, so numbers stay crisp at any zoom and print size.

You can place numbers in six positions (top or bottom × left, center or right), use the formats “1”, “Page 1”, “Page 1 of N” or “1/N”, start from any number and skip a cover page. Margins are measured in PDF points (72 pt = 1 inch).

Your PDF is processed entirely in your browser and is never uploaded. Original text, images, links and page sizes are preserved; only the numbers are added. Password-protected PDFs must be unlocked first.

Frequently asked questions

How do I add page numbers to a PDF for free?

Open this tool, drop your PDF, choose a position and format, then click Add page numbers. The numbered PDF downloads instantly with no signup, watermark or upload.

Can I skip the first page or cover?

Yes. Turn on Skip first page and numbering starts on page two. The start number you set is used for the first numbered page.

Can I use the format Page 1 of N?

Yes. Choose Page 1 of N or 1/N. N is calculated automatically from the number of numbered pages and your start number.

Are my files uploaded?

No. The PDF is read and edited locally with JavaScript, so your document never leaves your device. The tool also works offline.

Will adding page numbers reduce quality?

No. The original page content is kept as-is. Numbers are added as vector text on top of each page, so nothing is re-compressed or rasterized.
