Client photos stay on this device

Client photos are opened, developed and exported by your browser on this device, and are not uploaded. The photo privacy check shows what a file carries, such as location and camera details, and can remove it before you send it.

Questions

Short, honest answers.

More on the privacy and install page.

Does it open RAW files?

Yes. Phone DNG files open with the site’s own reader, and camera formats such as CR2, CR3, NEF, ARW and RAF open with an optional decoder of about 1 MB that downloads from this site when you first need it.

Do I need to install anything?

No. It runs in the browser. You can install it as an app and use it offline after the first visit.

Are my edits destructive?

No. Edits are settings stored with the photo, so the original is never changed and any step can be changed or removed.
