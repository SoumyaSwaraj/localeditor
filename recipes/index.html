Open a recipe, see what it does, then use it on your own photo. Experts can save their steps as a .leworkflow file. The file is data. It cannot run code.

From LocalEditor

On this device

The file

A recipe uses the format localeditor-workflow version 1.0. Share it as name.leworkflow. It can list steps, a strength slider, the author’s name, and an export suggestion. LocalEditor checks every step against a fixed list before running it.

If a step needs something this device cannot do, you will see that before it is skipped.
