Questions

Short, honest answers.

More on the privacy and install page.

Will a coloured code still scan?

Yes, while the dots stay clearly darker than the background. Contrast, margin and picture size are checked and the code is read back before you download. Try it with your own phone as well: the check uses a software reader, not a camera.

Do my links go anywhere?

No. The code holds exactly what you typed. There is no redirect, no tracking and no account.

Can I add a logo?

Yes. The code switches to its strongest repair setting and the picture is kept to at most 30 per cent of the width so it still reads.

Can I make many at once?

Yes. Paste rows or open a CSV or Excel file and get a zip of codes or a labelled print sheet. Formulas are never run.

Can I use it in a design?

Yes. Open it in the editor, or copy it and paste it into the studio, and it stays an editable code.
