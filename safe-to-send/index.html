Safe to send

One step before a PDF leaves your hands.

Makes a new copy of a PDF that is ready to send: scripts and automatic actions removed; author, software, dates, attachments, hidden text and earlier versions removed; forms and comments flattened and the file made smaller, if you leave those on. The new copy is checked and a list shows what changed.

Make it safe to send

FreeNo accountNothing uploaded

What it does

  • Removes scripts, automatic actions and attached files
  • Removes author, software, dates, hidden text and earlier versions
  • Flattens forms and comments: how they look stays, the data behind them goes (on by default)
  • Options to remove clickable links, and to make the file smaller (on by default)
  • Checks the new copy and lists what was done

How it works

  1. Open the PDF, choose Protect, then Make it safe to send.
  2. Choose the options: flatten, remove links, make smaller.
  3. Prepare the copy, read the checks and download it.

Your files stay on this device

Everything happens on this device. Your original file is not changed.

Questions

Short, honest answers.

More on the privacy and install page.

Will people still be able to fill in the form?

Not with the default setting. Flattening makes the current answers part of the page. Turn it off to keep the form.

Does it redact?

No. What is visible on the page stays. Use redaction to remove content from the page.

Does it work on a password-protected PDF?

Not directly. Take the password off the file first, then clean it.
