Template links

Share a template as a link, never your photos.

Make a link that opens a copy of your layout, text, colours and shapes. Photos are not included, so whoever opens it adds their own. The template sits after the # in the link, the part browsers do not send to a server.

What it does

  • Layout, text, colours, shapes and icons in one link
  • Photos are left out: the person who opens it fills the empty photo slots
  • An optional credit line, shown as Originally by you
  • A QR code to scan, when the link is short enough
  • If a design is too big for a link, it says so and offers a design file instead

How it works

  1. Open your design and choose Share as template link, from the File menu or the Download panel.
  2. Add a credit if you like, and copy the link.
  3. Whoever opens it sees a preview, then adds their own photos.

Your files stay on this device

The template is stored in the link itself, after the #, which browsers do not send to a server. Photos are never part of it.

Questions

Short, honest answers.

More on the privacy and install page.

Can a template link run code?

No. A link carries design data only. The studio checks it against a fixed list of allowed fields, and shows a preview before anything is opened.

How do I share a design with its photos?

Save it as a design file with photos included, or as a project file, and send the file.

How long can a link be?

Up to about 30,000 characters. A meter shows how full it is.
