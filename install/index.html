Install and offline use

Install it once, use it without a connection.

LocalEditor installs from the browser like an app. Once installed, the studios and tools open from your home screen or dock and keep working without a connection.

Install the app

FreeNo accountNothing uploaded

What it does

  • Install from Chrome, Edge or Samsung Internet on Android and computers
  • Add to Home Screen from Safari on iPhone and iPad
  • The studios and tools open offline after the first visit
  • Open images and project files from your device's share sheet or file manager where supported
  • Updates install quietly and never interrupt work in progress

How it works

  1. Tap Install the app, or use your browser's Install or Add to Home Screen option.
  2. Open LocalEditor from your home screen or dock.
  3. Use it on a train, a plane or anywhere without signal.

Your files stay on this device

Installing does not create an account or send anything about you. The app is stored by your browser, and the storage manager shows how much space it uses.

Questions

Short, honest answers.

More on the privacy and install page.

Do I have to install it?

No. Everything works in a normal browser tab. Installing makes it open faster and work offline more reliably.

How do I uninstall it?

Remove it like any other app from your home screen or your browser's app settings, and clear its storage in the storage manager first if you want.
