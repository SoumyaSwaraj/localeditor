What it does

  • Staff, visitor, student and event badges in five styles, colour-coded by type
  • Card size (85.6 × 54 mm, tall or wide) and two lanyard sizes, A6 and 4 × 3 in
  • Photo, name, role, ID number and a valid-until date, with the ID number as a QR code
  • A dashed guide for the lanyard slot, an optional back with a signature line, and a print sheet with cut marks
  • One badge per row of a list, with photos matched by file name. Export images, one PDF or print sheets

How it works

  1. Choose who the badge is for, then fill in the name, role and ID number and add a photo.
  2. Choose a style and a size, then tap Make it. The badge opens in the editor.
  3. Download it, add a print sheet, or tap Make one for each row of a list to make the whole team.

Questions

Short, honest answers.

More on the privacy and install page.

Can I make badges for everyone from a spreadsheet?

Yes. Tap Make one for each row of a list, then paste your list or choose a CSV, TSV or Excel file. Columns called name, role and id fill the badge, and the QR code follows the id column. Put each person's photo file name in a column called photo and choose the photos in the Photos step. The match ignores capitals and the file ending, so amara.jpg matches Amara.JPG or amara.

What is in the QR code?

Only the ID number you typed, as plain text. It is not linked to any system. What a scan does depends on the reader you use.

Which sizes are there?

The standard card, 85.6 × 54 mm, tall or wide, and two lanyard sizes, A6 (105 × 148 mm) and 4 × 3 in. Nine cards fit on an A4 print sheet.

Can I print on a plastic card printer?

The page is exactly card size with no bleed, which suits printing on paper or card and cutting, or a badge holder. Card printers differ, so switch off the slot guide and check your printer's own template before a large run.

Is this a secure ID?

No. It is a printed badge with a photo and a number. It has no chip or hologram and is not checked against any register.
