Mail-merge PDFs

One template, one PDF per person.

Use a PDF with form fields, or with {{column}} placeholders, as the template. Add a spreadsheet, match the columns and get one PDF per row. Name the files from a column, and add a password per person and a name watermark if you want.

What it does

  • Templates: a PDF form, or text with {{column}} placeholders typed in the studio or in Word before saving as PDF
  • Data: CSV, TSV, Excel or ODS files, or pasted rows, up to 2,000 rows
  • Matches columns for you; change any that are wrong, and step through the rows to check each one
  • One file per row in a zip, named from your columns
  • Optional password per person, from a column or a pattern, and the person’s name as a watermark

How it works

  1. Open Bulk, then Mail-merge, and choose the template.
  2. Add the spreadsheet and match the columns.
  3. Set file names and passwords, check a few rows, and download the zip.

Your files stay on this device

Questions

Short, honest answers.

More on the privacy and install page.

Which spreadsheets work?

CSV, TSV, Excel (.xlsx, .xlsm, .xls) and OpenDocument (.ods) files, or rows you paste in. The first row holds the column names.

Can each person get a different password?

Yes, if you choose: from a column, or built from a pattern. Keep your own list of them, since a lost password cannot be recovered.

How are files named?

From the columns you choose, so each file can carry the person’s name or ID.
