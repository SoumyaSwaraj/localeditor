LocalEditor is a set of 33 utilities that run inside the browser. Nothing is uploaded.

Privacy

Image edits use the canvas. PDFs use pdf-lib and pdf.js. Hashes and passwords use the Web Crypto API. There is no account, and the pages do not send the file to a server. After the app is installed, the tools that have already loaded keep working without a connection.

Install

  • Android (Chrome, Edge, Samsung Internet): tap Install app in the header, or open the browser menu and choose Install app / Add to Home screen.
  • iPhone & iPad (Safari): tap the Share button, then Add to Home Screen.
  • Desktop (Chrome, Edge): click the install icon in the address bar.

After your first visit, all 33 tools and their libraries are cached locally for permanent offline use.
