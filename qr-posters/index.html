QR signs and posters

A code people scan, on a sign you print.

Three makers that put a QR code on a printable page: a Wi-Fi sign whose code joins your network, a counter poster whose code opens a payment, and an invitation whose code opens the RSVP, the map or the address.

What it does

  • Wi-Fi sign: the code joins the network, and the password is printed too, in five styles
  • Pay poster: a UPI code made from your own UPI ID, or a code for any payment link, with an optional amount
  • Invitation: five occasion styles, with a code for the RSVP, the map or the address
  • Table-tent, A5, square and print sizes
  • Codes are drawn on your device in dark on light, with a quiet border, so they scan reliably

How it works

  1. Pick the maker you need and type the details: network name and password, UPI ID or link, or the invitation text.
  2. Choose a style and size.
  3. Tap Make it, test the code with your phone, then print.

Your files stay on this device

What you type, including a Wi-Fi password, a UPI ID or a link, is used on this device to draw the code. Nothing is uploaded. Whoever scans the printed code can read what is in it.

Questions

Short, honest answers.

More on the privacy and install page.

Is the Wi-Fi password in the code?

Yes. A code that joins a network has to carry the password, so anyone who scans it can join. Print it only where you are happy for people to have access.

Does the pay poster take payments?

No. It only draws a code for your own UPI ID or link. Payments go through the payer’s app and your payment provider.

Will the code scan?

Keep it at least about a quarter of the page width, print it dark on light, and test it with a phone before printing a lot of copies.

Can I edit the result?

Yes. A maker produces ordinary layers. Tap any part to change it, move it or replace a photo, or use Edit details to reopen the form and remake the page.
