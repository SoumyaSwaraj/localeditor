Questions

Short, honest answers.

More on the privacy and install page.

Does it work on scanned PDFs?

A scan has no text to compare, so the list of word changes is empty and the picture view does the work. Make the scans searchable first if you want their words compared.

Does it notice text that only moved?

No. Words are compared in reading order, so text that only moved to another line or page is not reported as a change. The picture view shows moves.

Does it show who changed the file?

No. It compares the two files you give it, not their history.

Is it a legal comparison?

It is a review aid. It can miss a change that is only in a picture or in a font, so read important documents yourself too.
