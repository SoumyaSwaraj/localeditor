Agent mode

Let an AI agent edit a design while you watch.

Agent mode lets a coding agent that can drive a browser make and edit a design in your own studio tab. You see each change happen, you can interrupt at any moment, and any single change can be undone.

What it does

  • The agent works in your own browser tab, in a design you can see
  • Each batch of changes is one undo step, listed in an activity feed where any single change can be undone
  • Pause, stop, take over or turn agent mode off at any moment; your own edits always win
  • Pin a note to a layer or a spot, such as “make this warmer”, and the agent reads it
  • A built-in check for text that overflows, low contrast, missing photos and unknown fonts

How it works

  1. Ask your agent to open the studio with ?agent=1, or choose File, then Agent mode, yourself.
  2. Read the short explanation and choose Turn on agent mode. Only you can do this.
  3. Watch the changes, add notes, pause or take over, then download the result.

Your files stay on this device

Agent mode runs inside the open studio tab, and LocalEditor sends nothing anywhere. The agent sees only the open design: not your saved designs, not stock photo keys, and only files you pick. It can use a picture from the web only after you allow that website. Your agent is a separate program; what it sends to its own provider is between you and that provider.

Questions

Short, honest answers.

More on the privacy and install page.

Who turns it on?

You do. The agent cannot press the buttons that allow agent mode, or the ones that pause, stop or take over. Those belong to you.

Can an agent run code in my browser through this?

No. Changes are plain data, checked by the same gate as a design file. Anything with scripts or HTML is refused, and a batch of changes is applied completely or not at all.

What if my agent can only open links?

It can send a link that carries its changes. You see what will change and must press Apply changes before anything happens.

What can it make?

Pages, text, shapes, icons, photo slots, collages, quick makers and recipes. Live agent operations do not include the Expert mode effects.
