Strong Password Generator

This password generator creates strong random passwords and passphrases using your browser's cryptographically secure random number generator — free, private and fully offline.

    How to generate a strong password

    1. Choose Password or Passphrase mode and set the length or number of words.
    2. Toggle the character sets you need and optionally exclude ambiguous characters like 0/O and l/1.
    3. Click Generate, check the strength meter, then copy the password or generate a bulk list.

    What is Password Generator?

    A password generator is a tool that builds unpredictable passwords from random choices. This one uses crypto.getRandomValues, the Web Crypto CSPRNG built into every modern browser, never Math.random.

    Each character is chosen with unbiased rejection sampling, so every symbol in the pool is equally likely. Strength is measured as entropy: length × log2(pool size) bits. 60+ bits is strong for most accounts; 80+ bits is very strong.

    Passwords are generated locally and are never sent, logged or stored. The page works offline once loaded, and the passphrase mode uses a built-in list of 416 words.

    Frequently asked questions

    Is this password generator secure?

    Yes. It uses crypto.getRandomValues, the browser's cryptographically secure random generator, with rejection sampling to avoid modulo bias. Passwords are created on your device and never transmitted or stored.

    How long should my password be?

    Use at least 14–16 characters with mixed character sets for important accounts. That gives roughly 90 or more bits of entropy, which is far beyond practical brute-force attacks.

    What is password entropy?

    Entropy measures unpredictability in bits. It equals length multiplied by log2 of the pool size. Each extra bit doubles the number of guesses an attacker needs.

    What is passphrase mode?

    Passphrase mode joins several random words, such as river-maple-orbit-quill. Five or six words are easy to type and remember while still giving strong entropy.

    What does exclude ambiguous characters do?

    It removes look-alike characters such as 0, O, o, 1, l, I and | so passwords are easier to read and type by hand without mistakes.

    Does it work offline?

    Yes. After the first visit the page is cached by the app, so you can generate passwords with no internet connection.
