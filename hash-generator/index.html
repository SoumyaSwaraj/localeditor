What is Hash Generator (MD5/SHA)?

A hash generator computes a fixed-length fingerprint (digest) of data with a cryptographic hash function. The same input always gives the same hash, and changing a single byte changes it completely, which is why hashes are used to verify downloads and detect tampering.

This tool computes five algorithms at once: MD5 (128-bit, 32 hex characters), SHA-1 (160-bit, 40 hex), SHA-256 (256-bit, 64 hex), SHA-384 (384-bit, 96 hex) and SHA-512 (512-bit, 128 hex). The SHA family uses the browser's built-in Web Crypto API (crypto.subtle.digest); MD5 is implemented in plain JavaScript because Web Crypto does not include it. Text is hashed as UTF-8 bytes.

Files are read locally and never uploaded, so you can safely check large ISOs or private documents. MD5 and SHA-1 are broken for security purposes; use SHA-256 or stronger for anything security-sensitive.

Frequently asked questions

Which hash algorithm should I use?

Use SHA-256 or SHA-512 for security and integrity checks. MD5 and SHA-1 are fast but have known collision attacks, so use them only to match legacy checksums.

How do I verify a file checksum?

Switch to the File tab, drop the downloaded file, then paste the checksum published by the provider into the Verify box. A green Match badge shows the hashes are identical.

Can I reverse or decrypt a hash?

No. Cryptographic hashes are one-way functions. You cannot recover the original text from a hash, only compare it with the hash of a known input.

Why do I get a different hash than another tool?

Hashes depend on exact bytes. Trailing spaces, line endings (CRLF vs LF) and text encoding change the result. This tool hashes text exactly as typed, encoded as UTF-8.

Are my files uploaded to compute the hash?

No. Hashing runs entirely in your browser with the Web Crypto API and a local MD5 implementation, so files never leave your device and the tool works offline.
