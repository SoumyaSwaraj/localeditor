Your files stay on this device

Each tool runs in your browser. Text you paste and files you open are not sent anywhere, including passwords and hashes, which use the browser's own cryptography.

Do the tools work offline?

Yes, after the first visit. Installing the app keeps every tool available without a connection.

Is there a file size limit?

There is no set limit. Very large files depend on your device's memory and are easier on a computer.
