Split by text

One long file into one file per person.

Turns one long PDF into one file per employee, student or invoice. Choose how to find where each file starts, check the list of parts, and download a zip with each file named after what was found.

Split by text

FreeNo accountNothing uploaded

What it does

  • Split on a label in the page text, such as “Employee ID”; click the value on the page preview to fill the label in
  • Or split every few pages, by top-level bookmarks, at blank pages, or by file size
  • Name the files from the text found, the part number or the original name
  • See the list of parts before anything is saved
  • Download everything as one zip

How it works

  1. Open Bulk, then Split by text, and choose the long PDF.
  2. Choose where a new file starts, and how to name the files.
  3. Check the list of parts and download the zip.

Your files stay on this device

The file is split on this device. Nothing is uploaded.

Questions

Short, honest answers.

More on the privacy and install page.

Does it work on scanned pages?

Only where the page contains text. A scan that is just a picture has no text to find, and the preview tells you so.

Can I check before splitting?

Yes. The parts are listed first, and nothing is saved until you download.

What if the PDF has a password?

Unlock it first with Password-protect or unlock.
