How to pick a color from an image

  1. Drop or paste an image (PNG, JPG, WebP, GIF or SVG).
  2. Hover to preview colors in the loupe, then click a pixel to lock it.
  3. Copy the HEX, RGB or HSL value, or click any swatch in the extracted palette.

What is an image color picker?

An image color picker reads the exact red, green and blue values of a single pixel and converts them to color codes such as HEX (#1e90ff), RGB (rgb(30, 144, 255)) and HSL (hsl(210, 100%, 56%)). This tool draws your image to an HTML5 canvas and reads pixel data with getImageData, so the value is exact, not estimated.

The palette is built with k-means clustering: the image is downsampled to about 10,000 pixels, grouped into 8 clusters, and sorted by how much of the image each color covers. In Chrome and Edge, the Pick from screen button uses the native EyeDropper API to sample any color on your display.

Everything runs locally. Your image is never uploaded, and the tool works offline once loaded.

Frequently asked questions

How do I get the HEX code of a color in an image?

Upload the image, then click the pixel you want. The HEX, RGB and HSL values appear instantly with Copy buttons. Use the zoom loupe to land on the exact pixel.

How is the color palette generated?

The image is sampled down to about 10,000 pixels and grouped into 8 clusters with k-means. Each swatch is the average color of a cluster, sorted by coverage.

Can I pick a color from outside the image?

Yes, in Chrome, Edge and Opera. Click Pick from screen to use the browser's native EyeDropper and sample any pixel on your display.

Does the tool upload my image?

No. The image is drawn to a canvas in your browser and never leaves your device. The tool also works offline.

Why does the color differ slightly from my design app?

Browsers may convert images with embedded color profiles to sRGB. The picker reports the sRGB value your browser displays, which is what matters for web use.
