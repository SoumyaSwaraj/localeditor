What it does

  • A value or an offer, to and from, a code, a valid-until date and your terms, in five styles
  • DL (210 × 99 mm) and A6 for print, and a 1600 × 900 size to send by message or email
  • The code as a QR code as well, for a quick check at the till
  • A print sheet with cut marks on A4 or US Letter
  • A numbered run from a list: one voucher per row with its own name, value and code

How it works

  1. Fill in the value or offer, your business, the code and the terms.
  2. Choose a style and a size, then tap Make it. The voucher opens in the editor.
  3. Download an image to send or a PDF to print, or tap Make one for each row of a list for a numbered run.

Your files stay on this device

What you type, the photos you add and any list you bring stay on this device. The design, the QR codes and the exported files are made by your browser, and nothing is uploaded.

Questions

Short, honest answers.

More on the privacy and install page.

Can I make these from a spreadsheet?

Yes. Tap Make one for each row of a list. Columns called to, from, value and code fill each voucher, and the QR code follows the code column. Paste cells or choose a CSV, TSV or Excel file, then save a zip of images, one PDF or print sheets.

Does the code do anything?

No. The maker prints the code you give it and draws it as a QR code. Keeping track of which codes are issued and used is up to you, for example in the same spreadsheet.

How many print on a sheet?

One DL voucher on a sheet turned sideways, and two A6 vouchers. Vouchers print at full size with a margin for the printer, so a DL voucher, which is as wide as A4, cannot share the sheet.

Can I leave To and From blank?

Yes. Leave them empty and the voucher has two lines to write on by hand.

Can I change the result?

Yes. It opens in the editor as an ordinary design. Tap any part to change it, or use Edit details to reopen the form and remake it in one undo step. If a design is already open, the new pages are added after the page you are on.
