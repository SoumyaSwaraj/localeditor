Command line and MCP

Make designs from the terminal, with the real editor.

For developers and agents. The localeditor command runs the same text measuring, fonts, shapes and renderer as the studio in a headless browser on your own computer. Write a design file, check it for problems, render a picture and fix what you see. It also runs as an MCP server and a local API.

What it does

  • Create, change, check and render design files (.ledesign.json)
  • An MCP server, with setup files for several agent tools in the agent kit
  • Problem checks: overflowing or clipped text, low contrast, missing images and unknown fonts
  • A live link that opens the design in a browser tab and keeps it in step with the file
  • Runs on your machine, and the engine cannot reach the network

How it works

  1. Install Node 20 or later, and Chrome, Edge, Chromium or Brave.
  2. Set up the command or the MCP server with the instructions in the agent kit.
  3. Create a design, apply changes, check, render and repeat until it looks right.

Your files stay on this device

The engine runs in a headless browser on your own machine and cannot reach the network. A remote image link in a design is reported, not fetched. Nothing is sent to LocalEditor.

Questions

Short, honest answers.

More on the privacy and install page.

Is there an npm package?

The setup files are written for one, but a published package is not available. Until there is one, the command runs from the tools/le-cli folder of the repository with Node.

How is this different from agent mode?

Agent mode is for working with a person who watches in an open tab. The command line is for fast work that nobody needs to watch. Both use the same operations.

What do I need installed?

Node 20 or later and a Chromium-based browser. The doctor command checks the setup.
