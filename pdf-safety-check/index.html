Is this PDF safe to open?

Check a PDF before you open it elsewhere.

Reads the inside of a PDF for scripts, actions that run on their own, attached files and links to outside addresses, and reports what it finds in plain language. Nothing in the file is run.

Check a PDF

FreeNo accountNothing uploaded

What it does

  • Scripts and actions that run when the file opens
  • Attached files, including programs
  • Links to outside addresses
  • Tricks such as disguised names, extra data after the end of the file and earlier versions inside

How it works

  1. Open the PDF, choose Protect, then Is it safe to open?
  2. Read the verdict and each finding.
  3. If something is flagged, make a safe copy: active content is removed and attached files are left out. The pages stay the same.

Your files stay on this device

The file is only read. Nothing in it is run and nothing is uploaded.

Questions

Short, honest answers.

More on the privacy and install page.

Is this a virus scanner?

No. It reports risky features of a PDF, such as scripts and automatic actions. It does not replace security software.

Does it open or run the file?

No. The file is read as data. Nothing inside it is executed.

What does the safe copy change?

It removes active content and leaves out attached files. The pages look the same.
