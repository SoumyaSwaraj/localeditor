Optional module: Camera RAW support (owner-approved exception to the licence rule)

Owner-approved exception. This one optional component is licensed under the GNU Lesser General Public License, version 2.1, which is outside the permissive-only rule the rest of the site follows. It is a separate download that is fetched only when you open a camera RAW file, runs in its own Web Worker, and can be removed from the storage manager at any time.

Where to get the licence and the source

  • Licence text: GNU LGPL 2.1 (LibRaw is also offered under the CDDL 1.0; LocalEditor uses it under the LGPL), and LibRaw's copyright notices.
  • Source of the module: LibRaw 0.22.2, unmodified, https://github.com/LibRaw/LibRaw/tree/0.22.2, plus LocalEditor's glue and build recipe in tools/raw-decoder/ of the LocalEditor source. Every source file and its SHA-256 is listed in tools/raw-decoder/sources.json.
  • Written offer. The complete corresponding source of the Camera RAW support module is available to anyone who has received it, for at least three years from the day that version was last served. Ask at [contact address, to be set by the owner].
  • Replacing it. The editor talks to the module only through a small message interface, so you (or a host that embeds LocalEditor) can swap in your own build of LibRaw or another decoder. See assets/vendor/raw-decoder/README.md.

Exception. On 12 November 2026 the owner decided that camera RAW formats may use the decoder that covers the most cameras, as an optional download with its licence shown to the person, limited to this module. LibRaw is LGPL-2.1 (dual-licensed LGPL-2.1 / CDDL-1.0), which is outside the MIT / ISC / BSD / Apache / OFL rule, so it lives in its own section and its own directory and nothing else may follow it. Conditions, and where each is met: separate file in assets/vendor/raw-decoder/, loaded only when a camera RAW file is opened, in a Worker, never bundled or linked into editor code (assets/js/raw/raw.js talks to it only by postMessage); replaceable (interface and steps in assets/vendor/raw-decoder/README.md); downloaded through LE.downloads and cached in le-models-v1 (x-le-model: raw-camera, listed in the storage manager as "Camera RAW support"); licence shown once at first use, in the storage manager, and at /licenses/#libraw; licence text, copyright notices, exact source version and hashes, build script (no patches) kept in this repository. Never precached.
