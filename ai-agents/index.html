Nothing is sent from the page

Agent mode works inside your browser tab and LocalEditor sends nothing anywhere. The command line runs a headless browser on your own machine. Your agent is a separate program: what it sends to its own provider is between you and that provider.

Questions

Short, honest answers.

More on the privacy and install page.

Where should an agent start?

With the agent guide. It is one document and explains the live channel, the operations, the errors and how to work with a person who is watching. The agent kit has short instruction files that point to it.

Is there a plain summary for language models?

Yes, llms.txt at the root of the site lists every page and tool in plain text.

Can an agent use the Expert mode effects?

Yes. Expert effects are readable data on each layer. An agent can add, change, mask and remove them live or from the command line, and a design file it writes can carry them. Making depth and face maps, opening camera RAW files and merging HDR are not agent operations yet.
