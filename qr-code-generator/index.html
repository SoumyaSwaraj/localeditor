What this QR code maker does

A QR code stores a short piece of text, usually a link, in a grid of dark and light squares. Phone cameras read it and open the link, join the Wi-Fi network, save the contact or start the payment it holds.

Here the squares can be dots, bars, soft diamonds or connected shapes, in one colour or a gradient, with styled corners, a logo or photo in the middle, a dimmed picture behind, and a frame that says what to do. Wi-Fi codes use the standard WIFI:T:WPA;S:name;P:password;; format, contacts use vCard 3.0, events use iCalendar and payments use the UPI link format.

Because a pretty code that does not scan is useless, the page checks every change: colour contrast, the empty margin, how much the picture covers, and a real test scan at two sizes. A code that fails cannot be downloaded without you choosing “Download anyway”. Everything is made on your device, so nothing you type is uploaded and the codes never expire.

Frequently asked questions

Will a coloured code still scan?

Yes, when the dots stay clearly darker than the background. Every change is checked: the page measures the contrast, the empty margin and how much a picture covers, then reads the code back with a real decoder at two sizes. If it fails you are told why and offered the one fix, such as Make the dots darker.

Do my links go anywhere?

No. The code is drawn in your browser and holds exactly what you typed. There is no redirect, no tracking link and no account, so the code keeps working for as long as the link itself does. Wi-Fi passwords, contact details and pictures stay on this device.

Can I put a logo or photo in the middle?

Yes. Choose a centre picture and the dots behind it are cleared for a rounded plate. The code switches to its strongest repair setting and the picture size is capped at 30% of the width so it still scans.

Can I make many codes from a spreadsheet?

Yes. Open Make many, paste rows copied from a spreadsheet or open a CSV, TSV or Excel file, and pick the column that holds the content. You get a zip of PNG or SVG files, or a PDF sheet with cut marks. Cells are read as plain text and formulas are never run.

Should I download PNG, SVG or PDF?

Use PNG for websites, documents and messages. Use SVG for print and signs because it stays sharp at any size. Use PDF when you want to print one code on a page or a sheet of them.

Do these QR codes expire?

No. They are static codes that store your content in the pattern itself, so they do not depend on any server.
