Per-recipient watermarks

A watermark per recipient, so a leak can be traced.

Type or paste a list of recipients, or load a spreadsheet, and get one copy of the PDF for each person with their name in the watermark. A hidden copy number and a summary.csv help you find out whose copy was shared.

Watermark copies

FreeNo accountNothing uploaded

What it does

  • Recipients one per line, or from a spreadsheet
  • Watermark text with the recipient’s name, today’s date and a copy number
  • Diagonal, tiled or footer style
  • A hidden copy number in the file’s properties and in tiny print on every page, listed in summary.csv
  • All copies in one zip

How it works

  1. Open Bulk, then Watermark copies, and choose the PDF.
  2. Add the recipients and set the watermark text and style.
  3. Check the preview and download the zip.

Your files stay on this device

The copies are made on this device. Nothing is uploaded.

Questions

Short, honest answers.

More on the privacy and install page.

Can a watermark be removed?

A determined person can crop, cover or retype content. A watermark deters and traces; it does not prevent.

Is the name visible?

Yes, in the style you choose. The copy number is also hidden in the file and printed small on each page.
