How to create a favicon

  1. Choose Image and drop a square logo, or choose Text / Emoji and type one to three characters.
  2. Set the background color, padding and corner radius while watching the live preview.
  3. Download favicon.ico, the PNG icons and copy the HTML and manifest snippets into your site.

What is a favicon?

A favicon is the small icon browsers show in tabs, bookmarks and history. Modern sites need several sizes: a favicon.ico with 16, 32 and 48 px images for legacy browsers, a 180×180 apple-touch-icon for iOS home screens, and 192×192 and 512×512 PNGs referenced from a web app manifest for Android and PWAs.

This generator renders each size on an HTML5 canvas with high-quality downscaling, then builds a real ICO file in JavaScript: a 6-byte ICONDIR header, one 16-byte directory entry per size, and PNG-compressed image data (supported by all browsers since Windows Vista-era ICO spec). Non-square images are centered and fitted.

Everything is generated on your device. Nothing is uploaded, and the tool works offline.

Frequently asked questions

What favicon sizes do I need?

Use favicon.ico (16, 32, 48 px) for browsers, a 180×180 apple-touch-icon for iOS, and 192×192 and 512×512 PNGs in site.webmanifest for Android and installable web apps. This tool creates all of them.

Is the favicon.ico a real ICO file?

Yes. It is a genuine multi-size ICO container built in JavaScript with embedded 16, 32 and 48 px PNG images, which all modern browsers and Windows support.

Can I make a favicon from an emoji or letter?

Yes. Choose Text / Emoji, type up to three characters, and pick a background color, text color and corner radius. Emoji use your device's emoji font.

Where do I put the favicon files?

Upload the files to your site's root folder and paste the generated link tags inside the head of your HTML. Add the site.webmanifest file to the same folder.

Are my images uploaded?

No. All icons are drawn with the Canvas API in your browser. Nothing leaves your device, and the generator works offline.
