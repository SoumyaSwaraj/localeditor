How to merge PDF files

  1. Drop two or more PDF files into the box, or tap to choose them.
  2. Drag the files, or use the up and down arrows, to set the order.
  3. Press Merge PDF and download the combined document.

What is a PDF merger?

A PDF merger combines the pages of several PDF files into one new PDF, in the order you choose. This tool copies every page — text, images, fonts, links and vector graphics — without re-rendering, so quality stays identical to the originals.

Merging runs 100% on your device using the open-source pdf-lib library, and previews are drawn with Mozilla pdf.js. Your files are never uploaded, the tool works offline once loaded, and there is no file-count limit other than your device memory. Password-protected PDFs must be unlocked first.

Frequently asked questions

Is it safe to merge PDFs here?

Yes. Files are read and merged locally in your browser with JavaScript. Nothing is uploaded to a server, so your documents stay private.

How many PDF files can I merge?

There is no fixed limit. You can merge as many PDFs as your device memory allows; most phones handle dozens of typical documents easily.

Does merging reduce PDF quality?

No. Pages are copied as-is, including text, fonts and images, so the merged PDF looks exactly like the original files.

Can I change the order of the files?

Yes. Drag a file to a new position, or use the up and down arrow buttons. The merged PDF follows the order shown in the list.

Can I merge password-protected PDFs?

Encrypted PDFs cannot be merged reliably. Remove the password with the original app first, then add the unlocked file here.
